# 🌍 Travel Horizon

Travel Horizon is a modern and responsive travel website designed to inspire users to explore new destinations and plan their journeys. The website showcases travel destinations, tour packages, and travel-related information with a clean and user-friendly interface.

---

## ✨ Features

- 🌴 Attractive and modern UI design  
- 📱 Fully responsive for all devices  
- 🧭 Destination and tour showcase sections  
- ⚡ Smooth navigation and user experience  
- 🎨 Clean layout with engaging visuals  

---

- CSS3  
- JavaScript
